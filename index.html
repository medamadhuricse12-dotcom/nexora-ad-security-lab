Lab Architecture

  • DC01: Windows Server / Active Directory Domain Controller — lab IP 192.168.56.128.
  • WS01: Windows 10 domain workstation — lab IP 192.168.56.130.
  • Network: VMware Host-only network. WS01 ping to DC01 succeeded (4/4 replies).
  • Service account: svc_sql with registered SPN MSSQLSvc/sql01.nexora.local:1433 for controlled lab study. SPN registration does not prove a SQL service exists.

Implemented Features

  • Domain nexora.local and domain-joined WS01.
  • OUs including HR, Finance, IT, Engineering, Management, Servers, Service Accounts, and Administrative Accounts.
  • Security groups: IT Support, Finance Team, Developers, Server Operators, Helpdesk.
  • Lab service account and SPN registration.
  • SMB share C:\NexoraShare and test file readme.txt.
  • WS01-to-DC01 connectivity and share-access verification.

Validation Status & Next Steps

Verified: network reachability, share existence, test-file access, and SPN query.

Not yet verified: attack paths for credential exposure, Kerberos service-account risk, and delegated-permission/ACL abuse. These must be tested in the isolated lab and documented before claiming full completion.

Recommended defensive focus: least privilege, strong unique service-account passwords, no real secrets in shares, review of privileged group membership, and restoring the lab after testing.

Safety Scope

This is a lab-only educational project. Do not expose the domain controller, SMB, or AD services to the public internet. Use synthetic accounts and data only. This public page documents the project; it is not the live AD environment.
